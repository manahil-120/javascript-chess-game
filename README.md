# ♟️ JavaScript Chess Game

A browser-based chess game built with **HTML, CSS, JavaScript, and jQuery**.

This project features an interactive chess board where two players can play against each other directly in the browser.

## 🎮 Features

* Interactive 8×8 chess board
* White and black chess pieces
* Turn-based gameplay
* Piece movement
* Capturing opponent pieces
* Available-move highlighting
* Castling support
* Interactive animations
* Runs directly in a web browser

## 🛠️ Technologies Used

* **HTML5** — Page structure and chess board
* **CSS3** — Styling, animations, and visual effects
* **JavaScript** — Chess game logic and piece movement
* **jQuery** — DOM manipulation and event handling

## 🚀 How to Run

### Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start playing chess.

No additional installation or dependencies are required.
